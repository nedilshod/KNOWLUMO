## 01 — Hook

Welcome back to Knowlumo. In Episode One, we learned how to read sets, find intersections, and build unions. Now take one step further: what if one whole set sits inside another? By the end of this lesson, you will read subset notation, find a complement, and solve an original practice question. Grab a pen and pause whenever you need more time. Think of a small box of colored cards placed inside a larger box: that picture will guide every new idea today.

## 02 — Subset

A set A is a subset of B when every element of A also belongs to B. We write A is contained in B. Look at the cards: the small box holds one, two, three; the larger box holds one, two, three, four. Every small card is already in the larger collection, so A is contained. The larger set may have extra cards; that is allowed. The empty set is also a subset of every set, because it has no element that could break the rule.

## 03 — Proper subset

When A is contained in B but B has at least one element that A does not have, A is a proper subset. Our card example helps: A is one, two, three; B is one, two, three, four. A is strictly smaller because four is new. Equal sets are still subsets of each other, but neither is proper. On screen, the symbol with a line underneath means subset or equal, while the strict symbol means properly smaller and excludes equality.

## 04 — Symbols

Be careful with the notation. The symbol subseteq means contained, possibly equal. The symbol subsetneq means strictly smaller. Some textbooks use the plain curved symbol for proper subsets, so always check the definition in your course. For Knowlumo, we will keep the two symbols separate. This small distinction matters in exam-style questions, because a single missing element changes a true statement into a false one.

## 05 — Complement

A complement needs a universal set. The universal set U is the collection of everything we are discussing. If U is one, two, three, four, five, six, and A is one, two, three, then the complement of A is four, five, six. It contains exactly the elements of U that are not in A. Think of the larger box again: the complement is whatever remains when you remove the small box.

## 06 — Venn diagram

On a Venn diagram, draw a rectangle for U and a circle for A. Shade everything outside the circle but inside the rectangle. That shaded region is A complement. The circle and its complement never overlap, and together they rebuild the whole universal set. This picture is often faster than listing elements by hand, especially when U has many elements. The boundary of the rectangle is part of the universe, not a separate set.

## 07 — Set difference

Set difference answers a slightly different question. A minus B means keep the elements of A that are not in B. With A equals one, two, three and B equals two, three, four, A minus B is one. B minus A is four. Notice that set difference is not the same as a complement: a complement always refers to U, while a difference compares two sets directly. The order matters.

## 08 — Practice question

Now try this original practice question. Let U contain one, two, three, four, five, six. Let A contain one, two, three, and let B contain two, three, four. Which statement is true? Option A: A is a subset of B. Option B: the complement of A is four, five, six. Option C: A minus B is two, three. Option D: B is a subset of A. Pause the video now, check each element, and choose one answer.

## 09 — Solution

Let us check each option. A is not a subset of B, because one is missing from B. The complement of A inside U is four, five, six, so option B is true. A minus B is only one, not two, three. B is not a subset of A, because four is missing from A. That leaves one correct answer: B. Always compare against the universal set before you decide about a complement.

## 10 — Recap and outro

Recap the three ideas: a subset is contained; a complement is everything in the universal set outside the set; a set difference keeps only what survives from the first set.
