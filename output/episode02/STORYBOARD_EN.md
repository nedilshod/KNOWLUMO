# CSCA Math Episode 02 — object-first storyboard

Draft only. Long video: 1280x720, 30 FPS, about five minutes. Visual rule from the future-course style guide: `REAL OBJECT → LABEL → SYMBOL → RULE → PAUSE → PRACTICE`. Objects are drawn/generated assets, not copied from any other channel.

| # | Scene | Object-first visual | On-screen math |
|---|---|---|---|
| 1 | Hook | Small box of colored cards inside a larger box | `SETS INSIDE SETS` |
| 2 | Subset | Small card box nested in larger card box | `A = { 1, 2, 3 }`, `B = { 1, 2, 3, 4 }`, `A ⊆ B` |
| 3 | Proper subset | Extra `4` card outside the small box | `A ⊊ B` |
| 4 | Symbols | Two large symbol cards | `⊆` vs `⊊` |
| 5 | Complement | Rectangle of six numbered object cards; removed `1, 2, 3` | `U = { 1, 2, 3, 4, 5, 6 }`, `Aᶜ = { 4, 5, 6 }` |
| 6 | Venn diagram | Rectangle with circle; shaded outside region | `A ∪ Aᶜ = U`, `A ∩ Aᶜ = ∅` |
| 7 | Set difference | Two overlapping card groups, one side highlighted | `A \ B = { 1 }`, `B \ A = { 4 }` |
| 8 | Practice | Four option cards, think pause | `U`, `A`, `B`, options A–D |
| 9 | Solution | Crosses on A/C/D, gold highlight on B | `ANSWER B` |
| 10 | Recap + outro | Three compact object icons, then centered round Knowlumo avatar | `SUBSET · COMPLEMENT · DIFFERENCE`, static `SUBSCRIBE` artwork |

Math checks: `A ⊄ B` because `1 ∉ B`; `Aᶜ = { 4, 5, 6 }`; `A \ B = { 1 }`; `B \ A = { 4 }`; `B ⊄ A` because `4 ∉ A`. Only option B is true. The practice question is independent, not an official CSCA question.

The `SUBSCRIBE` card is static artwork, not a clickable YouTube end screen. No URL is burned into the video. Dynamic subtitles are generated from the actual WAV energy envelope; short words, long pauses, and scene boundaries still need by-eye/by-ear review before publication.
