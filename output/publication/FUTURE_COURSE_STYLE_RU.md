# Object-first visual system для будущих курсов Knowlumo

Внутренний документ на русском. **Не для публикации.** Все надписи, озвучка, субтитры и публичные метаданные остаются на английском.

Ветка: `arena/da8b0093-knowlumo`.

## 1. Решение владельца

- Стиль с реальными объектами **не применяется к уже готовому Episode 01**. Текущие `CSCA_Math_01_Sets_Full_With_Outro.mp4`, `CSCA_Math_01_Sets_Outro.mp4`, `CSCA_Math_01_Sets_Shorts_1080x1920.mp4`, обложки, названия, теги и голос остаются без изменений.
- Принцип «сначала предмет, потом символ» переносится в **другие/будущие курсы**. Владелец назвал математику как основное направление и физику как возможное будущее направление.
- Физика здесь означает **обсуждаемую возможность**, не анонс готового курса, не расписание, не список вышедших уроков и не обещание даты.
- Референс [Brain Station Advanced](https://www.youtube.com/watch?v=iTZfATpm0Yk) используется только как пример подачи. Не копируются его кадры, фото, миниатюра, логотип, точный заголовок, описание или конкретный дизайн.

## 2. Базовый принцип

`REAL OBJECT → LABEL → SYMBOL → RULE → PAUSE → PRACTICE`

1. Показать узнаваемый предмет или небольшую сцену.
2. Дать крупную английскую подпись.
3. Наложить математический/физический знак.
4. Сформулировать правило.
5. Дать паузу на обдумывание.
6. Показатьнезависимый практический вопрос и разбор.

Это не замена анимации, а дополнительный «крючок» в первые 3–5 секунд сцены. Формула по-прежнему появляется синхронно с голосом, а не раньше.

## 3. Ассеты и авторские правила

- Использовать только **свои, сгенерированные или явно лицензированные** изображения/объектные рендеры.
- Не брать готовые фото из ролика Brain Station Advanced, из случайных поисковых картинок или из стоков без проверки лицензии.
- Сохранять фирменную сине-голубую палитру Knowlumo, круглый аватар без животных, `KNOWLUMO`, `VISUAL LEARNING`, слоган `Learn. Explore. Grow.`
- Не копировать логотип, персонажей или конкретную композицию чужих каналов, включая MrBeast и Brain Station Advanced.
- Не добавлять эмодзи-кликбейт, «Only 1%», «Harvard/JEE/Olympiad», Patreon, «Siuuu», выдуманные URL, даты, число подписчиков, контакты или готовые курсы.

## 4. Что сохранить от текущего продакшена

- Длинные уроки: 1280×720, настоящие 30 FPS, H.264, AAC 44.1 kHz stereo, минимум ~5 минут реального объяснения.
- Shorts/Reels: 1080×1920, 30 FPS, 2–3 вопроса, паузы перед ответами, безопасные зоны под интерфейс платформы.
- Динамические субтитры: слова появляются только по фактическому WAV, будущие слова не показываются, последняя группа удерживается на паузе, формулы не перекрываются.
- Английская озвучка: отдельный выбранный голос; не выдавать его за точный клон предыдущего narrator.
- Заставка длинного видео: центрированный круглый аватар Knowlumo; нарисованный `SUBSCRIBE` — статичная графика, не кликабельная функция YouTube.
- Финальная карточка Shorts: реальная обложка соответствующего эпизода, без выдуманного адреса и без обещания «кликабельной карточки».
- Исходники и результаты разделены; скрипты сборки, тайминги и метаданные коммитятся; MP4 полностью декодируется перед передачей.

## 5. Универсальный шаблон сцены

```text
[00:00–00:04] OBJECT: крупный узнаваемый предмет / набор предметов
[00:04–00:08] LABEL: короткая английская подпись
[00:08–00:14] SYMBOL: { }, ∈, ∩, ∪, ∅, F = ma, v, λ …
[00:14–00:24] RULE: анимация того, что произносит narrator
[00:24–00:27] THINK: пауза, субтитр удерживает последнюю группу
[00:27–00:40] PRACTICE: вопрос → разбор → короткий recap
```

Для длинного урока сцены объединяются в модули с chapters. Для vertical Shorts берутся 2–3 самых визуальных модуля, без спойлеров ответа в первом кадре.

## 6. Адаптер для математики

Возможные объектные пары (примеры, не обязательный список):

| Тема | Объект | Английская подпись | Символ |
|---|---|---|---|
| Sets | цветные фишки, светофор, фрукты | `SHARED ELEMENTS` | `A ∩ B` |
| Union | два набора карточек | `EVERY ELEMENT ONCE` | `A ∪ B` |
| Empty set | пустая коробка и карточка `0` | `EMPTY ≠ ZERO` | `∅ ≠ { 0 }` |
| Functions | «машина» вход→выход | `ONE OUTPUT PER INPUT` | `f(x)` |
| Geometry | бумажные фигуры, плитки | `SAME AREA` | `A = …` |
| Probability | монета, кубик, фишки | `POSSIBLE OUTCOMES` | `P(E)` |

Математика остаётся точной. Объекты иллюстрируют числа и отношения, но не подменяют их. Практические вопросы — независимые, не «официальные экзаменационные».

## 7. Адаптер для физики — только если курс будет запущен

Это **не анонс курса**, а заготовка на случай, если владелец решит делать физику:

| Тема | Объект | Английская подпись | Символ |
|---|---|---|---|
| Motion | игрушечная машина / мяч | `CHANGE OF POSITION` | `v = Δx / Δt` |
| Forces | пружина, груз, магнит | `PUSH OR PULL` | `F = ma` |
| Circuits | батарейка, лампочка, провод | `CLOSED PATH` | `I = V / R` |
| Optics | линза, фонарик, экран | `LIGHT BENDS` | `θ` |
| Waves | пружина / рябь на воде | `OSCILLATION` | `λ`, `f` |

Нельзя выдавать эти примеры за уже снятые уроки, готовую программу или официальные материалы. Формулы и единицы нужно проверять по актуальным источникам перед рендером.

## 8. Ограничения CSCA и платформ

- Канал независимый; не называть его официальным CSCA и не скрывать, что требования вузов/экзамена могут меняться.
- Не обещать, что конкретный вопрос появится на экзамене.
- Не вставлять выдуманный URL до реальной публикации; Related Video и end screen настраиваются отдельно в YouTube Studio, если доступны.
- Для Instagram/TikTok не обещать кликабельную ссылку внутри MP4; настоящая ссылка появляется только после публикации и только там, где платформа её разрешает.
- Ничего не публиковать без подтверждения владельца. `@Knowlumo` считается рабочим именем, доступность агентом не проверялась.

## 9. Чек-лист перед новым эпизодом

1. Выбрать 3–5 объектов на эпизод, проверить права на ассеты.
2. Написать английский сценарий → разбить на сцены → подготовить WAV.
3. Собрать object-first анимацию в 30 FPS, не показывая будущие слова.
4. Проверить математику/физику, паузы, субтитры, безопасные зоны, полное декодирование MP4.
5. Сделать 16:9 обложку и 9:16 превью; отдельно вертикальную и квадратную обложки для Reels.
6. Подготовить английские title/description/tags/chapters/caption, без дат, метрик и выдуманных ссылок.
7. Сохранить источники отдельно от результатов, закоммитить скрипты и метаданные.
8. Отдать владельцу честный список «сделано / не сделано / проверить вручную».
