## 3. Что можно взять в Knowlumo, не копируя чужое

- **Принцип «сначала предмет, потом символ».** Показывать узнаваемый объект, затем накладывать `{ }`, `∈`, `∉`, `∩`, `∪`, `∅`. У нас сейчас наоборот: сначала формула, потом анимация чисел. Объектный слой можно добавить как дополнительный «крючок» в первые 3–5 секунд сцены.
- **Собственные объектные ассеты.** Светофор, фрукты, карандаш, кружка, книга, карточки с числами, цветные фишки. Использовать только свои, сгенерированные или лицензированные изображения. **Не брать кадры, фото, миниатюру, логотип или конкретный дизайн Brain Station Advanced.**
- **Сохранить математику без изменений:** `A={1,2,3}`, `B={2,3,4}`, `A∩B={2,3}`, `A∪B={1,2,3,4}`, `4∉A∩B`, `∅≠{0}`. Объекты иллюстрируют числа, а не подменяют их. Практический вопрос остаётся независимым, не «официальным экзаменационным».
- **Сохранить наши сильные стороны:** настоящие 30 FPS, динамические субтитры по реальному WAV, паузы на обдумывание, центрированный круглый аватар в заставке, безопасные зоны 1080×1920, финальную карточку с реальной обложкой, отсутствие выдуманного URL.
- **Не копировать агрессивные обещания.** `Everything You Need To Know...` неточно для 5:42. Текущий заголовок `Sets Finally Make Sense: Intersection, Union, Venn Diagrams & Practice | CSCA Math #01` — 86 символов, внутри лимита YouTube 100 [4](https://support.google.com/youtube/answer/57404?hl=en&co=GENIE.Platform%3DDesktop), и честнее по объёму. Для будущих «all-in-one» выпусков можно использовать слово `Complete`, только если ролик действительно покрывает весь модуль.

## 4. Черновик объектного варианта Episode 01

Если владелец попросит пересобрать, логичный вариант — **отдельный файл**, а не замена текущего:

1. `00:00` — крупный объектный кадр: три цветные фишки/светофор, поверх `A = { 1, 2, 3 }`, затем `B = { 2, 3, 4 }`.
2. `What is a set?` — реальные предметы на столе; повтор одного предмета перечёркивается, порядок меняется, подпись «ORDER DOES NOT MATTER / REPEATS DO NOT COUNT TWICE».
3. `Membership` — объект с номером `2` заезжает в рамку множества A; объект `4` остаётся снаружи, `2 ∈ A`, `4 ∉ A`.
4. `Venn diagram` — те же объектные карточки `2` и `3` перемещаются в пересечение кругов, `1` и `4` остаются в своих частях.
5. `Empty set` — пустая прозрачная коробка и отдельно карточка `{ 0 }`, чтобы визуально показать `∅ ≠ { 0 }`.
6. `Practice` — карточки `P={1,3,5,7}` и `Q={3,4,7}`, пауза, затем подсветка `3` и `7`, ответ B.
7. Обложка-вариант: один крупный узнаваемый объект + `SETS` / `MADE SIMPLE` / `CSCA MATH · EPISODE 01`, но с сине-голубой палитрой Knowlumo и круглым аватаром, без копирования чужой миниатюры.
